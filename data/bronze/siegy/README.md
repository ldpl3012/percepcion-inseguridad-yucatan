# SIEGY

Los PDF/HTML se descargan solo cuando la URL directa aparece en el catálogo con extensión `.pdf` o `.html`. Las respuestas se guardan tal cual en Bronze, con su URL original, fecha local de incorporación y SHA-256. Silver registra número de páginas y disponibilidad/longitud de texto extraíble, pero no duplica el texto mientras no se verifiquen licencias.

Referencia institucional: <https://datos.yucatan.gob.mx/boletines>.
