# Datos.gob.mx: incidencia delictiva

Coloca aquí los CSV originales de incidencia delictiva estatal, municipal y por víctima/fuero, descargados desde <https://www.datos.gob.mx/es/dataset/incidencia_delictiva>.

Los archivos no se fusionan entre sí porque su granularidad puede ser distinta. El pipeline procesa cada CSV por separado y genera un Parquet Silver versionado.
