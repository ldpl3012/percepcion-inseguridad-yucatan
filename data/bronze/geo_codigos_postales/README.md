# Códigos postales

`CP_Yuc.zip` procede del archivo local `percepcion_inseguridad_yucatan/04_geoportal_merida/CP_Yuc.zip` proporcionado para esta ingesta. Es un Shapefile poligonal de códigos postales, no un raster de elevación. El pipeline registra el ZIP y sus componentes extraídos sin sobrescribirlos.

URL de referencia declarada: <https://www.datos.gob.mx/dataset/codigos_postales_entidad_federativa/resource/b1882e65-7eda-49ad-83e4-574d5a0de62e>.
