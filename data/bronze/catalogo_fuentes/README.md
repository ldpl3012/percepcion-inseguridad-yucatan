# Catálogo documental

El libro `Percepción de inseguridad en Yucatán.xlsx` se usa para consultar nombres de recursos y URLs, no como tabla analítica. La ingesta automática solo considera las filas de SIEGY, Solicitud de datos / Gobierno y Scraping cuya URL termina directamente en `.pdf` o `.html`.

El archivo se conserva sin cambios. `_metadata.json` registra su hash y la fecha de incorporación local.
