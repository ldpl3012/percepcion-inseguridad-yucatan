# Artículos de noticias

La ingesta automática conserva únicamente respuestas HTML de URLs directas con extensión `.html` incluidas en el catálogo. No descarga páginas raíz ni endpoints dinámicos. Silver conserva metadatos y longitud del texto; el cuerpo íntegro no se duplica mientras no se verifiquen las licencias.

Consulta y revisa los términos de uso de cada medio antes de reutilizar su contenido.
