# Límite municipal de Mérida

El endpoint municipal indicado inicialmente respondió HTTP 400. La descarga usó como alternativa la capa pública `municipios_yucatan` de CONABIO, filtrada por la clave oficial `MUN_OFICIA=31050` (Mérida, Yucatán). El GeoJSON original y su hash se conservan directamente en `data/bronze/geo_limite_merida.geojson` y `data/bronze/_metadata.json`.

Servicio usado: <https://services3.arcgis.com/lJPpeQVgQ9Gdmm11/arcgis/rest/services/municipios_yucatan/FeatureServer/0/query>.
