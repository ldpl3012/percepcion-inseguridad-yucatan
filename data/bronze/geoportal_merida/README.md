# Geoportal de Mérida

Coloca aquí exportaciones originales XLSX, CSV o GeoJSON del <https://www.merida.gob.mx/geoportal>. La descarga y selección de capas es manual.

El ETL transforma actualmente hojas XLSX; GeoJSON queda preservado como Bronze hasta definir el esquema espacial y sus dependencias. Los libros existentes pueden estar vacíos y se informará esa condición.
