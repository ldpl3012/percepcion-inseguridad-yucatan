# Informes COPLADEM / Gobierno

Los PDF/HTML directos identificados en el catálogo se pueden descargar mediante `scripts/ingest/download_documents.py`. Los programas o páginas dinámicas sin extensión `.pdf` o `.html` no se descargan automáticamente. Silver registra páginas y disponibilidad/longitud de texto extraíble, pero no duplica el texto mientras no se verifiquen licencias.

Referencias: <https://www.merida.gob.mx/municipio/portal/gobierno/copladem/> y <https://www.merida.gob.mx/copladem/>.
